# Calculadora de Média Escolar

## Descrição
Este projeto calcula a média escolar de um aluno com base em três notas.

## Objetivo
Praticar conceitos básicos de Python, como variáveis, cálculos e estruturas condicionais.

## Tecnologias utilizadas
- Python 3
- GitHub
- Markdown

## Funcionamento
O programa recebe o nome do aluno e três notas, calcula a média e informa a situação final.

- Média maior ou igual a 7: Aprovado.
- Média maior ou igual a 5 e menor que 7: Recuperação.
- Média menor que 5: Reprovado.

## Como executar
1. Instale o Python 3.
2. Abra o terminal na pasta do projeto.
3. Execute o comando: python script.py
